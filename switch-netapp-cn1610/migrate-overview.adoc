= NetApp CN1610 클러스터 스위치를 사용하는 2노드 스위치 클러스터의 마이그레이션 옵션
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
2노드 스위치가 없는 클러스터가 있는 경우 NetApp CN1610 클러스터 네트워크 스위치가 포함된 2노드 스위치 클러스터로 중단 없이 마이그레이션할 수 있습니다. 마이그레이션 절차는 각 컨트롤러에 전용 클러스터 네트워크 포트가 2개 있는지 또는 1개 있는지에 따라 달라집니다.

대부분의 시스템은 각 컨트롤러에 두 개의 전용 클러스터 네트워크 포트가 필요합니다.

FAS22xx 노드는 각 컨트롤러에서 하나의 클러스터 포트를 허용합니다.

마이그레이션 옵션은 두 가지가 있습니다.

* link:migrate-switched-netapp-cn1610.html["스위치가 없는 클러스터에서 스위치가 있는 NetApp CN1610 클러스터 환경으로 마이그레이션"]
* link:migrate-fas22xx-systems.html["스위치가 없는 클러스터(단일 클러스터 네트워크 연결을 사용하는 FAS22xx 시스템)에서 마이그레이션"]
