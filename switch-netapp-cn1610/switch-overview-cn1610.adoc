= NetApp CN1610 클러스터 스위치에 대해 알아보세요.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NetApp CN1610은 16개의 10기가비트 SFP+ 포트를 제공하는 고대역폭 관리형 레이어 2 클러스터 스위치입니다. 이 페이지에서 스위치의 기능과 ONTAP 클러스터 네트워킹에서의 역할에 대해 자세히 알아보십시오.

이 스위치는 이중 전원 공급 장치와 고가용성을 위한 핫 스와핑을 지원하는 팬 트레이를 포함합니다. 이 1U 스위치는 표준 19인치 NetApp 42U 시스템 캐비닛 또는 타사 캐비닛에 설치할 수 있습니다.

이 스위치는 콘솔 포트를 통한 로컬 관리 또는 네트워크 연결을 통한 Telnet이나 SSH를 이용한 원격 관리를 지원합니다. CN1610에는 대역 외 스위치 관리를 위한 전용 1기가비트 이더넷 RJ45 관리 포트가 포함되어 있습니다. 명령줄 인터페이스(CLI)에 명령어를 입력하거나 SNMP 기반 네트워크 관리 시스템(NMS)을 사용하여 스위치를 관리할 수 있습니다.
